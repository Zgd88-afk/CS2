### 1.2 零样本测试结论（2026-10-05）

**模型完好，但 CS2 画面下"失明"（视觉域差距）：**

| 指标 | CSGO 训练帧 | CS2 实时帧 |
|---|---|---|
| 开枪概率（真实开枪帧 / 非开枪帧） | **0.286 / 0.051**（区分度 5.6 倍） | ≈ 0.000 |
| W 键概率 | 0.610（真实按键率 47%） | ≈ 0.05 |
| 鼠标分布熵（上限 3.14） | 1.10 | 0.03 |
| 鼠标档位命中率（随机基线 4.3%） | 40% | 恒指 0 档 |

交叉验证排除了"模型加载坏了"的假设：stateful / non-stateful 输出一致（value 1.376 vs 1.365），
对噪声帧和游戏帧的响应不同。结论：**2021 年 CSGO 画面 → 2026 年 CS2 画面（Source 2 光影/材质/色调）
超出预训练模型泛化能力**，需要让模型重新"认识"CS2 的画面。

## 3. 数据来源分析（为什么这样选）

**❌ 网上视频素材**：行为克隆需要「画面 + 当时键鼠操作」成对数据。视频只有画面——
WASD/开枪标签几乎无法可靠还原；各主播分辨率/准星/HUD/色彩不一致；还有剪辑、滤镜污染。
原论文当年爬的也是带内存元数据的实录，不是视频。

**❌ AI 自弈生成数据**：模型现在不会走路不会开枪，用它自己的错误示范训练 = 越学越废。

**✅ 你玩 + 我自动录（原作者微调路线）**：录制脚本自动 16fps 截屏 + 直读键盘
（GetAsyncKeyState，无需改键）+ 同步录 demo（Valve 官方记录每 tick 视角/按键，
事后 demoparser2 解析出精确动作标签并与帧对齐）。原论文仅用约 3 小时专家数据微调
即显著提升，量级已验证。**先 1 小时验证，有效再补到 2~3 小时。**

**未来可选**：CS2 官方 demo 回放 + 同步截屏可获得职业选手级数据（无需本人游玩），
工程复杂度高，列为进阶选项。

## 4. 四阶段实施计划

### 阶段一（全自动，约 40 分钟）：直方图匹配快速验证

零训练成本的 test-time adaptation：把 CS2 画面色彩分布实时映射到 CSGO 训练分布。

1. 从已下载的 CSGO 训练数据（`_downloads/ds/dm_july2021_expert_1.npy`）统计每通道色彩 CDF，
   保存参考分布 `cs2_style_ref.npz`
2. `cs2_config.py` 新增 `match_style()`：对抓帧做逐通道直方图匹配；`STYLE_MATCH` 开关控制
3. `tools_model_check.py --style on/off` 对比 live 帧指标：**成功标准** = 开枪概率区分度
   或鼠标熵显著回升（向训练帧水平靠拢）
4. 有效 → 实机 5 分钟观察行为；无效 → 记录结论，直接进阶段二

### 阶段一结论（2026-10-05，已完成）：无效，进入阶段二

`tools_model_check --style both` 实测（20 帧 live 对照）：

| 数据源 | 开枪概率 | W 键概率 | 鼠标熵 |
|---|---|---|---|
| CSGO 训练帧（参照） | 0.064（峰值 0.896） | 0.611 | 1.10 |
| CS2 原始 | 0.000 | 0.009 | 0.05 |
| CS2 + 直方图匹配 | 0.000 | 0.039 | 0.25 |

色彩分布只是域差距最浅层，Source 2 的场景结构/光影差异无法靠全局调色弥补。
判定：**直方图匹配不足以复活模型**，直通阶段二。（工具与开关保留：
`tools_model_check.py --build-ref/--style`、`cs2_config.match_style`，供后续复验。）

### 阶段二（你玩 + 我自动录）：CS2 数据录制

1. 交付 `dm_record_data_cs2.py`：
   - PrintWindow 16fps 截屏（复用 `grab_window_cs2`，**关闭风格匹配**——训练数据须与
     部署画面一致）
   - GetAsyncKeyState 直读 `W A S D 空格 ctrl shift 1 2 3 R` + 左右键（无需改键）
   - 提示并指导你在控制台 `record cs2_ft_01`；事后用 demoparser2 解析每 tick
     视角角度/按键位掩码，与屏幕帧时间对齐，得到鼠标位移与按键的精确标签
     （若 demoparser2 按键解析不可用，退回纯键鼠实时记录方案）
   - 断点续录：每次启动自动接续文件编号，每 1000 帧存一个 `.npy`
2. **你来玩**：dust2 离线死斗、AK47、灵敏度 2.5、正常准星，按平时习惯打，累计 1 小时
3. 数据验收：帧数 / 标签对齐误差 / demo 解析完整性报告

### 阶段三（自动，训练数小时，可过夜）：微调

1. 新预处理脚本：录制帧 + 动作 → 训练用 `.hdf5`（兼容现有 `DataGenerator`：
   鼠标档位量化到 `mouse_x/y_possibles`、onehot 标签、击杀/死亡 helper 事件——从 demo 解析）
2. 从预训练底模 `ak47_sub_55k_drop_d4`（zip 内 non-stateful 版）微调，TF 2.10 单卡，
   先 3~5 epoch，学习率 1e-4
3. `tools_create_stateful.py` 逻辑在 TF 2.10 下重建 stateful 推理模型
4. `tools_model_check` 验证 live 指标：**成功标准** = live 帧开枪概率/鼠标熵达到
   训练帧同量级

### 阶段四：实机验证 + 标定 + 定量评估

1. 鼠标转角标定：你开 `cl_showpos 1`，跑 `dm_run_agent_cs2.py --calibrate`，
   记 6 个 yaw 读数（5 分钟）→ 计算 `MOUSE_SCALE` 写入 `cs2_config.py`
2. 实机 5 分钟验证「遇到人就打」行为（你观察确认）
3. 达标后定量评估：固定 bot 配置（6 easy / 无限弹药 / 每局 10 分钟）× 5 局，
   demo 解析 K/D、K/min 汇总表
4. 每阶段完成并经你确认后提交推送 github

### 5.5 录制纪律（数据质量红线）

- 游戏窗口保持**前台可见**，别最小化、别切出游戏
- **不按 Tab**（计分板会污染画面），不弹菜单，不改任何设置，不开购买菜单
- 正常水平打，主动索敌开枪，多换区域（A/B/中路/出生点都逛）
- 中途休息按 **Q**，回来续录自动接编号

### 5.5.1 打法要点（针对性修正「撞墙」和「不打人」）

模型 = 数据里你行为的镜像。录制时按下面的清单打，能直接教会 AI 正确行为：

| ✅ 要这样做 | ❌ 要避免 | 教会 AI 什么 |
|---|---|---|
| 提前转弯、沿开阔路线走，**不要贴墙蹭走** | 顶墙走、沿墙摩擦、反复顶同一个墙角 | 撞墙数据 = 教 AI「见墙继续顶」 |
| 时刻保持移动（搜点、转点、小走位） | 长时间站桩等敌人、蹲角落挂机 | 站桩数据 = 教 AI 原地不动 |
| 视线保持平视（敌人出现在眼睛高度） | 长时间看地板/天花板 | 低头数据 = 教 AI 看地板走 |
| 主动找 6 个 bot 打，准星瞄躯干再开枪 | 对着墙/烟乱扫、不瞄就泼水 | 乱扫数据 = 教 AI 乱扫 |
| 近/中/远距离都打几波 | 只在一种距离接战 | 多距离样本 = 不同大小的敌人轮廓 |
| 左转右转大致均衡 | 长时间只往一边转 | 均衡 = AI 不产生转圈偏置 |
| 死了没关系，重生继续打 | —— | 死亡镜头帧占比小，影响可忽略 |

**预期管理**：1 小时数据能显著改善撞墙和接战开枪，但走位精度仍有限（鼠标控制是
16fps 离散档位）。撞墙问题的另一半在部署端——「模型想转 X 度 vs CS2 实际转的度数」
标定（第 4 节阶段四第 1 步），录完数据后做。

## 6. 风险与安全边界

1. **只打离线 bot 局**：模拟键鼠输入不用于任何对战/官方服务器；账号建议用小号
2. 训练数据里你的操作水平 = AI 的天花板，录制时按正常水平打即可，不必刻意表演
3. 微调过拟合风险：1 小时数据先验证方向，有效再扩充；训练/验证集按文件划分
4. TF 2.10 训练与原作者 TF 2.3 存在行为差异，但**训练与推理同版本，自洽**；
   若日后迁移回 TF 2.3 环境需重新训练
